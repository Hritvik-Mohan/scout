# John Doe - Job-search ICP

John Doe is fictional. This file shows what a finished ICP looks like; every
employer, project, and number in it is invented. Use it as a model, then write
your own from [`docs/icp-template.md`](../../docs/icp-template.md).

## Positioning

**Frontend engineer with four years of experience building React and TypeScript
web applications, who has owned a shared component library and led the
accessibility and performance work on a customer-facing checkout.**

The strongest evidence is ownership of things other teams depend on: a component
library used by five product teams, and a checkout rebuild that measurably
improved load time and conversion.

## Resume facts

These are the facts recruiters will check. Reviews and drafts must stay inside
them.

- **Timeline:** Frontend Engineer at Example Retail Ltd, London, since
  June 2024. Junior Frontend Developer at Sample Agency, Manchester, from
  September 2022 to May 2024.
- **What "four years" means:** four years of full-time frontend work, about two
  and a half under the current mid-level title. Roles asking 3-5 years are a
  direct fit; roles asking 6 or more are a stretch.
- **Main project:** rebuilt the checkout flow in React and TypeScript with
  Next.js. It is in production and serves all of the company's web orders.
  Largest Contentful Paint fell from 4.1s to 2.3s and checkout conversion rose
  by 3 percent, measured over the eight weeks after launch.
- **Component library:** maintains a 60-component library with Storybook
  documentation, used by five product teams. Introduced visual regression tests
  with Playwright.
- **Accessibility:** led the audit and fixes that brought the checkout to WCAG
  2.1 AA, verified by an external review.
- **Agency work:** built marketing sites and two small e-commerce storefronts
  for clients. These were short projects with small audiences, not products
  operated at scale.
- **Backend exposure:** has written Node.js API routes and GraphQL resolvers for
  frontend features. Has not designed a backend service or owned a database.
- **Leadership:** mentors one junior engineer and runs the frontend guild's
  monthly review. Has not managed people.
- **Languages and tools listed:** TypeScript, JavaScript, React, Next.js, CSS,
  HTML, GraphQL, Jest, Testing Library, Playwright, Storybook, Node.js.
- **Not in my background:** native mobile, backend system design, cloud
  infrastructure, Vue, Angular.
- **Education:** BSc Computer Science, University of Example, 2019-2022.

## Target roles

### Tier 1 - strongest fit

- Frontend Engineer / Frontend Software Engineer (mid-level)
- UI Engineer or Web Engineer
- Software Engineer II on a frontend or design-system team

### Tier 2 - strong adjacent fit

- Full-stack Engineer where frontend work is at least half the role
- Design Systems Engineer
- Product Engineer on a web product with a React codebase

### Tier 3 - selective applications

- Senior Frontend Engineer where the posting asks for 5 years or fewer
- Frontend roles in Vue or Angular that accept transferable React experience

## Roles to exclude

- Backend-only, data, machine-learning, DevOps, and SRE roles
- Native iOS or Android roles
- Staff, principal, architect, and engineering-manager roles
- Agency roles built around short client projects
- Manual QA, support, and design roles with no engineering

## Ideal company

- Product company with a customer-facing web application and a real design
  system, or the intent to build one
- A team that measures web performance and takes accessibility seriously
- Roughly 50-2,000 employees, with senior frontend engineers to learn from
- An interview loop built around practical frontend work, not only algorithm
  puzzles

## Location and eligibility

- **Cities:** London, on-site or hybrid up to three days a week.
- **Remote:** remote roles that hire in the United Kingdom as a direct employee.
- **Reject:** remote roles restricted to the US, the EU, or another region that
  excludes UK residents; roles requiring relocation.
- **Hours:** UK working hours, with occasional overlap into US East Coast
  mornings.

## Application rules

- **Apply now:** mid-level frontend role in London or UK-remote, React and
  TypeScript, asking 3-5 years.
- **Apply:** frontend-leaning full-stack roles, or design-system roles, at the
  same level.
- **Stretch:** senior titles asking 5 years or fewer; Vue or Angular roles that
  accept React experience.
- **Skip:** anything in the exclude list, roles asking 8 or more years, and
  remote roles closed to UK residents.
